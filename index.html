Como Abrir e Jogar os Projetos

Os oito projetos GameMaker podem ser jogados no navegador ou baixados; o projeto Unity continua disponível para Windows.

🎯

Jogos GameMaker em HTML5

  1. Escolha um dos oito projetos GameMaker no catálogo.
  2. Clique em Jogar; o jogo será aberto em uma nova aba.
  3. Aguarde o carregamento dos recursos e use os controles exibidos em Detalhes.
  4. Para jogar online, não é necessário instalar o GameMaker.
  5. Use Baixar para obter o projeto original e abri-lo no GameMaker.
⚡

Jogos Windows Standalone (.exe)

  1. Clique em Baixar no card do Wood Energy Tycoon para obter o instalador WoodEnergyTycoon.exe.
  2. Dê duplo clique no instalador, escolha a pasta e clique em Instalar e jogar.
  3. O instalador prepara os arquivos, cria atalhos e abre o jogo automaticamente; não é necessário descompactar.
  4. Compatível com Windows 10/11 x64; não requer Unity instalado.
📘

Competências Aplicadas (SESI / SENAI)

  • NR-10 & NR-12: Desenergização, testes de potencial zero e Lockout/Tagout.
  • Automação & Indústria 4.0: Roteamento de sensores, montadoras e esteiras.
  • Usinagem CNC: Coordenadas X/Z, avanço milimétrico e velocidade de corte (Vc).
  • Sustentabilidade: Matriz energética limpa a base de biomassa e solar.
